# OntaDev_Xray

xray-лампа для Paper: предмет, который подсвечивает цветным контуром выбранные блоки (руды и т.п.)
вокруг игрока сквозь стены. Подсветка рисуется только на клиенте через [ProtocolLib](https://www.spigotmc.org/resources/protocollib.1997/):
настоящих сущностей и блоков на сервере не создаётся, а при выключении лампы всё исчезает.

Построен на [OntaDev_Libs](https://github.com/OntaDev/OntaDev_Libs) (DI-контейнер, ORM, меню, YAML-конфиги).

## Возможности

- Лампа включается и выключается правым кликом, светится блеском зачарованности, пока работает.
- Подсветка следует за игроком и пересчитывается каждую секунду; если блоков больше лимита, показываются ближайшие.
- Заряд тратится, пока лампа включена; виден в action bar и в описании предмета. Заряжается топливом из инвентаря.
- Лампу можно держать в любой руке.
- Руда и её глубинный (deepslate) вариант подсвечиваются вместе.
- Каждый игрок скрывает материалы и красит их в свой цвет (16 цветов).
- Администратор меняет параметры лампы и общий список материалов в меню (блоки добавляются перетаскиванием из инвентаря) или командами.

## Требования

- Paper 1.16.5 - 1.19.4 (`api-version: 1.16`); Adventure берётся из Paper. На Spigot его нужно обеспечить отдельно (требование OntaDev_Libs 0.2.8)
- Java 11+
- [OntaDev_Libs](https://github.com/OntaDev/OntaDev_Libs) 0.2.8+ (отдельным плагином; NBT-API входит в него)
- [ProtocolLib](https://www.spigotmc.org/resources/protocollib.1997/) 5.x

Игроки на более новых клиентах подключаются к старым серверам через [ViaVersion](https://viaversion.com).

## Установка

Положите `OntaDev_Xray.jar` в `plugins/` рядом с OntaDev_Libs и ProtocolLib и перезапустите сервер.
Выдать лампу и топливо: `/xray give` и `/xray givefuel`.

## Управление

| Жест | Действие |
|---|---|
| ПКМ с лампой | включить или выключить подсветку |
| Shift+ПКМ | зарядить лампу топливом из инвентаря |
| ЛКМ в воздух | личное меню: показать/скрыть материал (ЛКМ), выбрать цвет (ПКМ) |
| Shift+ЛКМ в воздух | редактор лампы (радиус, перезарядка, лимит блоков, подсветка для всех, материалы) |

Из левой руки работают ПКМ и Shift+ПКМ; ЛКМ открывает меню, только если основная рука пуста.
Если убрать лампу из руки, подсветка гаснет.

Редактор общего списка материалов открывается кнопкой в редакторе лампы или командой `/xray materials`. Блок добавляется
Shift+кликом по нему в своём инвентаре либо кликом по меню, когда блок лежит на курсоре; ЛКМ по материалу открывает палитру
цветов, ПКМ удаляет. Сами предметы при этом не тратятся.

## Команды

| Команда | Описание |
|---|---|
| `/xray give [игрок]` | заряженная лампа (себе, если игрок не указан) |
| `/xray givefuel [игрок] [количество]` | топливо (себе 1, если без аргументов) |
| `/xray make <lamp\|fuel>` | превратить предмет в руке в лампу или топливо |
| `/xray materials [list\|add\|remove\|color]` | общий список материалов; без аргументов открывает редактор |
| `/xray lamp <info\|radius\|max\|cooldown\|forall\|material>` | параметры лампы в руке |
| `/xray my <list\|toggle\|color>` | мои скрытые материалы и цвета |
| `/xray reload` | перечитать список материалов из БД |

## Права

| Право | Назначение | По умолчанию |
|---|---|---|
| `lamp.use` | включать лампу | все |
| `lamp.gui` | личное меню и `/xray my` | все |
| `lamp.gui.edit` | открыть редактор лампы | op |
| `lamp.lamp.edit` | менять параметры лампы | op |
| `lamp.materials` | открыть общий список материалов | op |
| `lamp.materials.edit` | добавлять, удалять и красить материалы общего списка | op |
| `lamp.admin` | `/xray give`, `givefuel`, `make`, `reload` | op |

## Настройка

`plugins/OntaDev_Xray/config.yml` (значения по умолчанию для **новых** ламп; уже выданные лампы хранят настройки на предмете):

| Ключ | По умолчанию | Описание |
|---|---|---|
| `lamp.default-radius` | 10 | радиус подсветки, блоков |
| `lamp.default-max-highlighted-blocks` | 100 | сколько блоков подсвечивается одновременно |
| `lamp.default-cooldown` | 1 | перезарядка между включениями, секунд |
| `lamp.default-highlight-for-all` | true | видят ли подсветку игроки рядом |
| `lamp.default-materials` | алмаз, золото, изумруд | материалы новой лампы (должны быть в общем списке) |
| `lamp.refresh-interval-ticks` | 20 | как часто обновляется подсветка и списывается заряд |
| `fuel.fuel-item-material` | GLOWSTONE_DUST | предмет-топливо |
| `fuel.fuel-per-item` | 10 | заряд от одного предмета топлива |
| `fuel.max-fuel` | 100 | максимальный заряд |
| `fuel.fuel-cost-per-use` | 1 | цена включения |
| `fuel.fuel-drain-per-second` | 2.0 | расход включённой лампы в секунду |
| `item.lamp-material` | LANTERN | предмет лампы |

Изменения `config.yml` вступают в силу после перезапуска сервера.

## Хранение данных

- Параметры лампы (радиус, лимит, перезарядка, заряд, список материалов) лежат на самом предмете.
- Общий список материалов хранится в базе OntaDev_Libs (`plugins/OntaDev_Libs/settings.yml`), таблица `materials`.
- Личные цвета и скрытые материалы игрока живут в памяти и сбрасываются при выходе с сервера.

## Совместимость и ограничения

- С 1.19.4 контур рисуется блоком в полный размер (`BLOCK_DISPLAY`); на 1.16-1.18 это блок на голове невидимой стойки, он меньше настоящего.
  Клиентам старше 1.19.4 display-сущности не показываются.
- Версии новее 1.19.4 не проверялись.
- Paper 1.16.5 с ViaVersion 5 запускается только на Java 17 с флагом `-DPaper.IgnoreJavaVersion=true`.

## Сборка

Нужны JDK 11+ и Maven; OntaDev_Libs ставится в локальный репозиторий:

```bash
mvn install:install-file -Dfile=OntaDev_Libs.jar -DgroupId=com.ontadev -DartifactId=libs -Dversion=0.2.8 -Dpackaging=jar
mvn clean package
```

Готовый jar: `target/OntaDev_Xray.jar`. Тесты: `mvn test`.
